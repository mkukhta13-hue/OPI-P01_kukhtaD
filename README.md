# Стартовий проєкт: лабораторна робота 1

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`. Права адміністратора не потрібні. Потрібен лише `git` (версія 2.30 або новіша); обліковий запис GitHub для виконання роботи не обов'язковий.
2. Визначте свою задачу й набір за номером варіанта: задача = `(номер - 1) // 3 + 1`, набір = `(номер - 1) % 3 + 1`. Реалізуйте функції у файлі `variants/lab_NN.py` за карткою варіанта.
3. Запускайте відкриті тести своєї задачі й свого набору: `pytest tests/test_lab_NN.py -k S2` (замініть `S2` на свій набір: `S1`, `S2` або `S3`).
4. Змінюйте лише свій файл у `variants/` (і за бажанням додавайте `tests/test_my.py`).
5. Частина Б (за темою власного диплома): створіть локальний репозиторій `team-repo` проєкту вашого диплома (або запасного проєкту, див. розділ 9 студентського документа) і перевірте його командою `pytest repo_check`. Шлях до іншого репозиторію задає змінна `REPO`: `REPO=/шлях/до/репо pytest repo_check`.
6. Здача: `lab_NN.py`, `team-repo.bundle` (`git -C team-repo bundle create ../team-repo.bundle --all`), `ANSWERS.md` і знімок екрана.
